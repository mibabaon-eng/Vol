# Volleyball — Paper/Spigot 1.21.8

Плагин добавляет волейбольный мяч на базе невидимой стойки для брони с головой игрока.

## Сборка
Требуется JDK 21 и Maven:
```bash
mvn package
```
Готовый файл появится в `target/volleyball-1.0.0.jar`.

## Установка
1. Скопируй JAR в папку `plugins` сервера Paper 1.21.8.
2. Перезапусти сервер.
3. Выполни `/volleyball`.

## Управление
- `/volleyball` — создать мяч.
- Ударь по мячу левой кнопкой мыши, чтобы отбить его в направлении взгляда.
- Также можно нажать по мячу правой кнопкой мыши.

## Важно про текстуру
Сейчас используется стандартная голова игрока, поэтому специальная текстура волейбольного мяча ещё не задана. Для настоящей текстуры головы нужен URL текстуры Minecraft (или готовый Base64 texture value) — её можно встроить в следующую версию.
